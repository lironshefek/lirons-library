## בחירת ספר והצגת פרטים .

הספר שנבחר נשמר ומנוהל במצב המקומי של רכיב `App`, במשתנה `selectedBook`.
בעת לחיצה, `BookCard` מפעיל את `onSelect`, ו־`BookList` מעביר את אירוע הבחירה לפונקציית העדכון של `App`.
`App` מעדכן את הספר שנבחר, והכרטיס המתאים מקבל סימון פעיל.
`App` מעביר את נתוני הספר שנבחר אל `BookDetails` דרך המאפיין `book`.
`BookDetails` מציג את הכריכה, הכותרת, פרטי הספר ותגיות הז׳אנר שלו.
