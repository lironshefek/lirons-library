# Lirons Library 📚

ספרייה אישית של **מותחנים פסיכולוגיים** — אפליקציית React + TypeScript שמציגה ספרים
מ-[Open Library](https://openlibrary.org), עם חיפוש, דף פרטים, מועדפים, רולטת ספר-הפתעה
ורשימת ההמלצות האישית שלי.

פרויקט גמר בקורס **4255 · פלטפורמות מתקדמות לפיתוח ב-WEB ושימוש ב-AI**.

## הרצה

```bash
npm install
npm run dev
```

פתחו את הכתובת שמופיעה בטרמינל (בדרך כלל `http://localhost:5173`).

| פקודה | מה היא עושה |
|---|---|
| `npm run dev` | מריצה את האתר במצב פיתוח |
| `npm run build` | בודקת TypeScript ובונה גרסה לפרסום בתיקייה `dist/` |
| `npm test` | מריצה את כל הבדיקות בטרמינל |
| `npm run test:ui` | פותחת את ממשק הבדיקות של Vitest בכתובת `http://localhost:51204/__vitest__/` |

## מה יש באתר

| עמוד | כתובת | מה רואים |
|---|---|---|
| **בית** | `/` | כותרת גדולה, ערימת כריכות של 3 ספרים אהובים, כפתור "Surprise me", חיפוש לפי שם ורשת של 100 מותחנים פסיכולוגיים |
| **פרטי ספר** | `/books/:id` | כריכה גדולה, שם, סופר, שנת פרסום, דירוג, תיאור, ז׳אנרים וכפתור הוספה למועדפים |
| **My Picks** | `/picks` | 9 הספרים המומלצים שלי, שמורים מראש בקובץ ונטענים מיד |
| **מועדפים** | `/favorites` | הספרים שסימנתי בלב — נשמרים ב-`localStorage` גם אחרי רענון |
| **רולטה** | `/random` | כפתור Spin שמערבב את ספרי עמוד הבית ועוצר על ספר אקראי, עם כל הפרטים שלו: דירוג, ז׳אנרים ותיאור |
| **404** | כל כתובת אחרת | עמוד "Page Not Found" עם קישור חזרה |

### פרטים שכדאי לדעת

- **רשימת הספרים:** בקשה אחת ל-Open Library בטעינה — רק מותחנים פסיכולוגיים מ-2000 ואילך שיש להם כריכה.
- **חיפוש:** מסנן רק את הספרים שכבר מוצגים בעמוד הבית, לפי שם הספר (בלי בקשות נוספות).
- **ספרים שמורים מראש:** ספרי הכותרת (`src/data/heroPicks.json`, כריכות ב-`public/hero/`) ו-My Picks (`src/data/myPicks.json`) מוצגים בלי לחכות לשרת.
- **מצבי טעינה ושגיאה:** בזמן טעינה מוצגים כרטיסי שלד מהבהבים. כל בקשה מוותרת אחרי 5 שניות, ואז מופיעה הודעת שגיאה עם כפתור **Try again**.
- **תיאור הספר:** נטען בנפרד מ-`/works/{id}.json`. אם אין תיאור — כתוב "No description is available for this book".
- **רספונסיבי:** 5 עמודות במסך רחב, 2 בטלפון; הניווט, הכותרת והכפתורים מותאמים למסך קטן.

## עיצוב

עיצוב כהה ורגוע ("calm dark") עם צבע הדגשה סגול. גופנים: **Fraunces** לכותרות ולשם האתר, **Manrope** לטקסט.
כל ה-CSS מחולק לקבצים לפי תפקיד, וכל הערכים (צבעים, מרווחים, פינות, צללים) מוגדרים כמשתני CSS:

```
src/App.css               רק מייבא את שאר הקבצים לפי הסדר
src/styles/colors.css     פלטת הצבעים
src/styles/tokens.css     גופנים, גדלים, מרווחים, פינות, צללים
src/styles/base.css       הגדרות כלליות לכל העמוד
src/styles/layout.css     כותרת עליונה, תחתית ומסגרת העמוד
src/styles/components/    קובץ לכל רכיב
src/styles/pages/         קובץ לכל עמוד
```

## מבנה הפרויקט

```
src/
  App.tsx                 ניתוב (React Router), טעינת הספרים ומצב המועדפים
  api/openLibrary.ts      בקשות ל-Open Library (חיפוש, ספר לפי מזהה, תיאור) עם מגבלת זמן
  components/             רכיבים: BookCard, BookList, BookDetails, SearchBar, HeroSection,
                          SiteHeader, SiteFooter, ErrorMessage, EmptyState, שלדי טעינה
  pages/                  HomePage, MyPicksPage, FavoritesPage, RandomBookPage, NotFoundPage
  data/                   heroPicks.json, myPicks.json (נתונים שמורים מראש)
  types/book.ts           טיפוסי TypeScript לספר ולתשובות של Open Library
  utils/bookHelpers.ts    פונקציות טהורות: סינון, שנה, כתובת כריכה, בחירה אקראית, ניקוי תיאור
public/
  favicon.svg             אייקון האתר
  hero/                   כריכות ספרי הכותרת
```

## בדיקות

22 בדיקות עם **Vitest** ו-**React Testing Library**, בין היתר:

- פונקציות העזר (`bookHelpers.test.ts`) — סינון, שנה, כריכה, בחירה אקראית וניקוי תיאור.
- שורת החיפוש (`SearchBar.test.tsx`).
- הודעת שגיאה וכפתור Try again כשהשרת לא זמין (`App.test.tsx`).
- מגבלת 5 השניות לבקשות (`openLibrary.test.ts`).
- הרולטה בוחרת רק מספרי עמוד הבית (`RandomBookPage.test.tsx`).
- עמוד My Picks מציג את כל הספרים (`MyPicksPage.test.tsx`).

## טכנולוגיות

React 18 · TypeScript (strict) · Vite · React Router · Vitest · CSS רגיל (בלי ספריות עיצוב).
